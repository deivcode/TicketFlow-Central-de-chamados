# TicketFlow-Central de Chamados

Um projeto simples que estou desenvolvendo para praticar JavaScript e fortalecer meus fundamentos de programação.

## Sobre o projeto

Resolvi voltar a estudar JavaScript com mais profundidade e queria colocar o que estava aprendendo em prática, em vez de ficar apenas assistindo às aulas.

Então pedi ao ChatGPT que me propusesse um desafio adequado ao meu nível de conhecimento. A ideia foi criar uma pequena central de chamados que eu pudesse desenvolver aos poucos, conforme avançasse nos estudos.

O objetivo não é construir um sistema complexo de uma vez, mas entender a lógica por trás de cada funcionalidade e ganhar mais autonomia programando.

## Como estou desenvolvendo

A interface inicial em HTML e CSS foi fornecida com ajuda de IA, assim como a estrutura para conectar os botões às funções.

Minha parte do desafio é implementar a lógica em JavaScript, testar as funcionalidades, entender os erros e melhorar o código conforme aprendo.

Estou tentando resolver os problemas por conta própria e usar a IA principalmente para tirar dúvidas, receber explicações e revisar o que desenvolvi.

## Funcionalidades

- [x] Estrutura inicial do projeto
- [x] Cadastro de chamados utilizando arrays e objetos
- [ ] Exibição e consulta de chamados
- [x] Encerramento de chamados
- [x] Contagem de chamados
- [ ] Validações e tratamento de erros
- [ ] Filtros por status e prioridade

O projeto ainda está em desenvolvimento.

## Tecnologias

- **JavaScript:** lógica e manipulação dos chamados
- **HTML:** estrutura da interface
- **CSS:** estilização
- **Git e GitHub:** versionamento e acompanhamento da evolução

Nesta primeira versão, os chamados são armazenados em um array na memória, sem banco de dados.

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível executar o `app.js` pelo terminal utilizando Node.js para testar as funções.

## Próximos passos

Minha intenção é continuar evoluindo esse mesmo projeto conforme aprender novos conceitos.

Futuramente, quero transformá-lo em uma aplicação Full Stack com Node.js, uma API REST, banco de dados PostgreSQL e React.

## O que quero aprender com esse projeto

Mais do que decorar comandos, quero entender por que utilizamos determinados recursos, quando fazem sentido e como aplicá-los para resolver problemas.

Estou usando este repositório para registrar minha evolução, incluindo as funcionalidades implementadas, os erros encontrados e as melhorias feitas ao longo do caminho.

**Projeto pessoal de estudos — desenvolvido e aprimorado aos poucos.**
